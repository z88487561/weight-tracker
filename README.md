# ⚖️ 體重紀錄(Weight Tracker)

一個單檔、免安裝、完全在瀏覽器本機執行的體重紀錄網頁 App。設定目標後,自動算出每天應有的目標體重,每次記錄都會即時判定是否達成,並用圖表、連續達成天數與徽章幫助你持續下去。

- **無伺服器、無帳號、無追蹤**:資料只存在你自己的瀏覽器(localStorage),不會上傳。  
- **單一檔案**:`index.html` 無外部依賴(不需 CDN、不需 build)。  
- **手機友善**:可「加入主畫面」當 App 使用,支援離線。

## 功能

### 目標與計畫

- **兩種模式**  
  - **減重模式**:依起始體重、目標體重與期間,算出一條逐日下降的目標線;每次紀錄 ≤ 當天目標即為達成。  
  - **維持模式**:以目標體重為中心,落在 ± 區間內即為達成(預設 ±1 kg),適合達標後守住體重。  
- **兩種計畫方式**:指定「每週減重速率(安全上限)」讓系統反推期間,或直接指定「總週數」。設定時即時試算每週/每日減量與預計達標日。  
- **安全檢查**:每週減量超過上限(預設 0.7 kg/週)、超過每週體重 1%、或目標體重 BMI 低於 18.5 時,會顯示警告並要求確認。

### 記錄與回饋

- 記錄日期時間、體重、**時段標籤**(早晨空腹/睡前/餐後/運動後/一般)與備註。  
- 可**編輯、刪除、補記**;紀錄列表顯示當日目標與差距,可依時段篩選。  
- **每一筆都獨立判定**達成(綠)或未達成(紅)。  
- **教練回饋**:達成與未達成各 30 句訊息,洗牌輪播,用完一輪才會重複;連續 3 天未達成會改給調整建議,短時間掉太快會提醒放慢。

### 圖表與統計

- 折線圖(純 SVG):目標線(藍色虛線)、7 日移動平均(橘線)、達成/未達成的點(綠/紅)、未記錄日(灰色刻度)。  
- 可切換 **近 7 天 / 近 30 天 / 全期**;手機上點圖上的點可查看該筆資訊。  
- **BMI**(台灣標準分級)、進度百分比、**預估達標日**(以近 14 天趨勢估算);進度落後時可「重新規劃目標」。  
- **連續達成天數**與**徽章**(首次紀錄、連續 3/7/14/30 天、達成目標)。今天尚未記錄時連續天數顯示 0,記錄並達成後會接續昨天。

### 備份與資料管理

- **分享備份**(Android 可直接送到 Google Drive、LINE、信箱,需 HTTPS)與**下載備份 CSV**。  
- **匯入 CSV(覆蓋)**:以檔案內容取代目前所有紀錄與設定。  
- **合併匯入 CSV**:以「日期+時間」判斷重複,只補上缺少的紀錄;不刪除、不修改現有紀錄,時間相同但體重不同時保留目前版本。  
- 匯入或清除前會自動建立快照,可按「**還原**」復原一次。  
- **備份提醒**:距離上次匯出超過 7 天,頁面頂端會提醒。  
- **清除紀錄 / 重置全部資料**:顯示目前筆數、要求確認,並先自動下載 CSV 備份。  
- 會要求瀏覽器「持久儲存」,並顯示目前狀態。

### 其他

- **提醒通知**:可設定晨起與睡前時間(僅在頁面開啟時觸發,見下方限制)。  
- **PWA**:可安裝到主畫面、離線開啟(需 HTTPS)。  
- 首次開啟會顯示一次「資料儲存提醒」。

## 快速開始

### 方式一:使用線上網址(建議,手機也能用)

    線上網址:`https://z88487561.github.io/weight-tracker/`

### 方式二:本機開啟(僅電腦)

直接雙擊 `index.html`。功能可用,但**不會註冊 service worker**(無離線快取與安裝),Web Share 也不可用(會退回下載)。本機檔案的 localStorage 行為依瀏覽器而異,請特別留意備份。

### 第一次使用

1. 展開最上方「基本資料與目標」,填入身高、起始體重、目標體重、計畫方式與起始日,按「儲存設定」。  
2. 在「新增紀錄」輸入體重,按「儲存紀錄」。建議每天早晚各一次。  
3. 定期到「備份、提醒與資料管理」備份。

## 資料與隱私

- 所有資料存放在瀏覽器 localStorage,**不會傳送到任何伺服器**;程式沒有任何追蹤或分析。  
- 公開儲存庫公開的只有程式碼,不含你的資料。**請勿把匯出的 CSV 上傳到儲存庫。**  
- localStorage 依「**瀏覽器 \+ 網址**」分開存放。換瀏覽器、換網址(包含改儲存庫名稱或帳號)、換裝置,資料都不會跟過去。要搬家請先匯出 CSV,再到新環境匯入。

### 資料可能遺失的情況

- 清除瀏覽器的網站資料或快取、重設或更換裝置、解除瀏覽器。  
- 瀏覽器在空間不足時自動清除(App 會要求持久儲存以降低風險,但不保證)。

**請定期備份 CSV。** 備份檔同時保存目標設定與所有紀錄。

### CSV 格式

date,time,tag,weight,note

\#config,,,,"{...目標設定的 JSON...}"

2026-10-01,07:30,"早晨空腹",79.5,"備註"

- 第一欄為 `#config` 的列存放目標設定,其餘每列是一筆紀錄。

## 已知限制

- **不會自動跨裝置同步**。兩台裝置各自記錄後,可互相匯出並使用「合併匯入」湊齊;但合併**不處理刪除**,某一邊刪掉的紀錄可能被另一邊補回。  
- **提醒通知**使用頁面內的 `Notification`,只有網頁開著(或在背景存活)時才會觸發;Android Chrome 可能完全不支援這種寫法;iOS 需先加入主畫面。需要穩定準時提醒,得改用 service worker 通知或包成原生 App。  
- **PWA 與離線**需 HTTPS(或 localhost)。iPhone 上 Safari 與「加入主畫面」的 App 資料可能是分開的,請固定使用一個入口。  
- 預估達標日是以近期趨勢做線性估算,僅供參考。

## 技術細節

- 純 HTML / CSS / JavaScript,**無框架、無外部相依**;圖表以手寫 SVG 繪製。  
- 儲存鍵:`wt_v1`(主資料)、`wt_v1_prev`(匯入/清除前快照)。  
- 資料結構(`wt_v1`):  
    
  {  
    
    cfg:   { h, w0, wt, weeks, cap, d0, band, mode, pm },  // 目標設定  
    
    rec:   \[{ id, d, t, g, w, n }\],  // 日期、時間、時段、體重、備註  
    
    rem:   { on, m, n },             // 提醒設定  
    
    bg:    {},                       // 已獲得的徽章  
    
    coach: { m, c },                 // 最近一次回饋  
    
    rng, lastExp, intro, bag         // 圖表範圍、上次匯出、已讀提示、訊息輪播  
    
  }  
    
- 日期以 `YYYY-MM-DD` 字串處理,天數計算使用 `Date.UTC`,不受時區與夏令時間影響。  
- PWA manifest 以 data URI 內嵌,圖示為內嵌 SVG。
